## 这题不用现场推导整张 S-box

原题附件已经提供了 `s_box`、`inv_s_box` 和一个 4×4 的 `state`。最后调用的是：

```python
sub_bytes(state, sbox=inv_s_box)
```

因此这里要做逆向查表。正向与逆向的区别是传入哪张表：

```text
SubBytes:    新字节 = s_box[原字节]
InvSubBytes: 原字节 = inv_s_box[新字节]
```

AddRoundKey 是 XOR；SubBytes 是替换。先把这两件事区分清楚。

## 函数本身很短

```python
def sub_bytes(state, sbox):
    for i in range(4):
        for j in range(4):
            state[i][j] = sbox[state[i][j]]
    return state
```

这个版本会原地修改 `state`。需要保留原矩阵时，先复制每一行。

题目左上角是 `251`，查 `inv_s_box[251]` 得到 `99`，也就是 `c`。全部替换后还要按列表顺序转成 bytes。
